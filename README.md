# Vite Launcher

The launcher for **Unreal Engine Vite**, by Vite Studio.

**[Download the latest version](https://github.com/ViteStudio-Tech/Vite-Launcher-Releases/releases/latest)**: get `ViteLauncher-<version>-win64.zip`, unzip it anywhere and run `ViteLauncher.exe`. There's no installer.

- Install Unreal Engine Vite, keep it updated, switch branches and launch the editor
- Your Unreal projects, engine sample projects, packaged demos and benchmarks
- Vite Studio's Discord, documentation, repositories and videos in one place

## Requirements

- Windows 10 (1703 or newer) or Windows 11, 64-bit
- A processor with AVX2 (Intel 4th generation "Haswell", 2013, or newer; AMD Ryzen or newer)
- For installing and updating the engine: [Git for Windows](https://git-scm.com/download/win) and a GitHub account linked to Epic Games with [access to Unreal Engine Vite](https://github.com/ViteStudio-Tech/ueVite-Access)

## Updates

The launcher updates itself from this page's releases: when a new version is out it installs it at the next start, or offers **Restart now** while it's open. Only releases signed by Vite Studio are installed, and your settings are kept. **Settings › About › Releases** opens this page.

The first time, Windows may say "Windows protected your PC" because the program is new: click **More info**, then **Run anyway**.
